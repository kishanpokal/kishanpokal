## ⚡ Executive Summary

I am a software engineer based in Ahmedabad, specializing in native Android development and the integration of machine learning models into mobile ecosystems. My focus is on designing clean, scalable architectures and delivering high-performance applications that solve real-world problems.

* **Core Focus:** Native Android (Kotlin, Jetpack Compose), Machine Learning Integration, and Full-Stack System Design.
* **Current Endeavors:** Engineering production-ready platforms, including urban mobility solutions and AI-driven financial analytics.
* **Background:** B.Sc. in Computer Science (2022–2025), bridging the gap between strong theoretical foundations and practical, scalable engineering.
